Comment on your running app.
Claude makes the change.

Code Buddy is a Claude Code plugin: select text, point at an element or draw on your dev app in the browser, write what to change, and a background agent makes the change and answers in the same thread.

Install Read the docs GitHub

Right on the page

Comment on selected text, an element, a drawn area or freehand lines, the page or the whole app. Paste a screenshot or a mockup.

One agent per comment

Each comment gets its own background agent, on a model that fits it. File locks keep parallel agents out of each other’s way.

Nothing in production

Your project only gets a dev-only loader snippet and a config file. init checks the widget is not in your production build.

Install

With Claude Code 2.1.287 or later and Node.js 22 or later, in your frontend project: 

claude plugin marketplace add neolitec/code-buddy#stable
claude plugin install code-buddy@code-buddy
claude "/code-buddy:code-buddy init"

Then run /code-buddy in the session, open your dev app and click the Comment icon. The full install covers folders, monorepos, updates and uninstalling.
