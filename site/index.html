Comment on your running app.
Claude makes the change.

Annotant is a Claude Code plugin: select text, point at an element or draw on your dev app in the browser, write what to change, and a background agent makes the change and answers in the same thread. No mockup, no artifact: the change lands in your code.

Install Read the docs GitHub

Right on the page

Comment on selected text, an element, a drawn area or freehand lines, the page or the whole app. Paste a screenshot or a mockup.

One agent per comment

Each comment gets its own background agent, on a model that fits it. File locks keep parallel agents out of each other’s way.

Nothing in production

Your project only gets a dev-only loader snippet and a config file. init checks the widget is not in your production build.

Get started

From nothing to a first comment on your app, in four steps.

  1. Check the requirements

    • Claude Code 2.1.287 or later: claude --version, and claude update when it is older.
    • Node.js 22 or later: node --version.
    • A web frontend served by a dev server: Next.js, Vite, CRA, Astro, SvelteKit, Angular, or a plain index.html.

  2. Install the plugin

    Straight from GitHub, no clone needed:

    claude plugin marketplace add annotant/annotant#stable
claude plugin install annotant@annotant

  3. Set it up in your project

    Start Claude Code in your frontend project, and run:

    /annotant:annotant init

    It detects the framework, the dev URL, the checks and the folders agents may edit, and asks only what it could not find. It adds a dev-only loader snippet and .annotant.json, then builds your app to prove the widget stays out of production. In a folder of a monorepo: /annotant:annotant init web.

  4. Start commenting

    /annotant

    Open your dev app, its dev server running as usual: a strip of icons shows in the bottom right corner. Click Comment, write what to change, and send it. No icons? The widget does not show.

Comment the way you would review

  • Select text

    Then Comment: a typo, a label, a sentence to rewrite.

  • Point at an element

    A button, a card, a section: the agent gets its selector and its HTML.

  • Draw an area

    The gap between two blocks, a misaligned group, empty space.

  • Draw freehand

    An arrow to where a block should go, a circle around a detail.

  • Paste an image

    A screenshot or a mockup, in any comment or reply.

  • Comment the page

    Or the whole app, when the change is not about one spot.

Then let Claude work

  • One agent per comment, in the background, on a model that fits it: send several, they work in parallel, with file locks between them.
  • Its steps show live under your comment (files read and edited, commands), with Cancel at hand.
  • It answers in the thread, or asks when the comment is unclear. Reply to follow up: the same agent picks it up, with its context.
  • Your session stays yours: comments go straight to their agents, never through your conversation.

Commands

/annotant
Watch the app; /annotant web for a folder.
/annotant status
The server, the agents at work and the comments waiting.
/annotant stop
Stop watching. Closing the session stops it too; nothing is lost.
/annotant:annotant update
Migrate a project after an update (claude plugin marketplace update annotant).
/annotant:annotant uninstall
Remove the loader and the config; it asks before deleting comments.
